# 快速启动指南

## 前置要求

- Node.js 18+ 
- npm / yarn / pnpm
- 后端服务运行在 `http://localhost:8080`

## 快速开始

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问应用

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

## 使用示例

1. **查看股票数据**：
   - 在顶部输入框输入股票代码（如：`AAPL`）
   - 点击"查询"按钮
   - 查看股票价格走势图表

2. **查看AI持仓**：
   - 输入AI模型代码（如：`AI001`）
   - 右侧面板显示持仓和收益信息

3. **与AI对话**：
   - 在底部输入框输入问题
   - 按Enter或点击发送按钮
   - 获取AI投资建议

## 常见问题

### 后端连接失败

- 确保后端服务已启动
- 检查 `next.config.mjs` 中的代理配置
- 确认后端运行在 `http://localhost:8080`

### 数据加载失败

- 检查浏览器控制台的错误信息
- 确认后端API返回的数据格式正确
- 查看网络请求是否成功

### 样式显示异常

- 确保 TailwindCSS 已正确安装
- 运行 `npm run build` 检查构建错误

## 开发提示

- 使用 `npm run lint` 检查代码规范
- 使用浏览器开发者工具调试
- 查看 `README.md` 了解更多信息
